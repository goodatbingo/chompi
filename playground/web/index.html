What runs here

TAPE runs DSPEngine.h: seven streaming voices, the varispeed looper, filter, saturation, warble, delay and reverb. WAVE runs subtractiveEngine.h with its wavetable loader. TEMPO runs the chromatic and slice engines, the arpeggiator and its clock, and the granular delay. A small stand-in layer replaces the board: an SD card in memory using the real FatFs, the system timer, and 48-frame audio blocks as on the hardware. The panel and LEDs are not emulated; the controls here call the same engine functions the panel code calls.
